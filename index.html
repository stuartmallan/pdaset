Read, Don't Rehearse

Mixing random pressures forces real-time problem-solving instead of predictable muscle memory.

When the cue is unannounced, the attacker no longer knows which pressure is coming. Each repetition becomes a decision, not a rehearsal — so the reaction has to be read from the partner's body, not recalled from the drill order.
